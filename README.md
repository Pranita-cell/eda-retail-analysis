# 🛍️ Retail Customer Analytics — Exploratory Data Analysis

## 📌 Project Overview
This project performs a full Exploratory Data Analysis (EDA) on a retail customer dataset
of 500 records. The goal is to uncover hidden patterns, correlations, and business insights
that can drive smarter marketing and sales decisions.

## 📂 Files Included
| File | Description |
|------|-------------|
| `EDA_Report.xlsx` | Full report with dashboard, raw data, pivot tables & insights |
| `EDA_Dashboard.png` | Overview visualization — KPIs, distributions, scatter plots |
| `EDA_Analysis.png` | Deep-dive charts — correlations, heatmaps, regional analysis |

## 📊 Dataset Features
- **500 customers**, 11 variables
- Age, Income, Gender, Region, Category, Purchase Amount, Spending Score, Loyalty Years, Satisfaction, Returns

## 🔍 Key Findings
1. **Income is the #1 predictor** of purchase amount (r = 0.80)
2. **Spending Score** explains 33% of purchase variance (r = 0.57)
3. **South region** leads in volume and average transaction value
4. **High-satisfaction customers** have 2× lower return rates
5. **26–35 age group** shows the strongest purchase intent

## 🛠️ Tools & Skills Used
- Python (Pandas, NumPy, Matplotlib, Seaborn, SciPy)
- Statistical analysis (correlation, descriptive stats, distribution analysis)
- Data visualization (heatmaps, violin plots, scatter plots, KPI dashboards)
- Excel (openpyxl — pivot tables, conditional formatting, multi-sheet reports)

Developed end-to-end analytical thinking — from raw data to structured business insights,
